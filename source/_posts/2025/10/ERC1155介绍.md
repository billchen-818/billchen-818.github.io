## ERC1155

ERC1155是用于多种代币管理的合约标准接口，单个部署的合约可以包含同质化代币、非同质化代币等。所以ERC1155代币就具有与ERC20和ERC721代币相同的功能。

### 功能与特点

**批量转账**

```solidity
function safeBatchTransferFrom(
    address _from,
    address _to,
    uint256[] calldata _ids,
    uint256[] calldata _values,
    bytes calldata _data
) external;
```

批量转账需要传id数组和value数组。

**批量余额**

可以获取多个地址，多种代币的余额情况。

```solidity
function balanceOfBatch(
    address[] calldata _owners,
    uint256[] calldata _ids
) external view returns (uint256[] memory);
```
